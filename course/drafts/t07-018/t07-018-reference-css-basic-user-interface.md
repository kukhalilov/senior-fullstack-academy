# How this group fits the mental model

These properties style browser-facing control affordances such as appearance, caret, focus outline, cursor, text selection, resize, and pointer interaction. Recent `interactivity` and `interest-delay*` properties also connect CSS to inertness and Interest Invoker event timing; their support and behavior are still evolving. # Common mistakes

- Removing focus outlines without an equally visible replacement.
- Using `pointer-events: none` as a way to disable a control.
- Assuming `appearance: none` removes native semantics or validation.
- Applying `user-select: none` broadly and preventing useful text selection.
- Assuming a property listed by an index is a stable or interoperable standard.
- Treating a shorthand, alias, vendor extension, or draft property as interchangeable with its neighboring names.
- Skipping value grammar, inheritance, cascade, and applicable-box details in the linked definition.
