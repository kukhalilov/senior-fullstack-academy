# Scheduled draft generation

GitHub Actions rebuilds the lesson queue from the topic manifests and runs the worker automatically every six hours. It uses the stable `gemini-3.5-flash-lite` API model and reads `GEMINI_API_KEY` from repository secrets. Each run has a hard limit of 100 actual HTTP requests, counting retries and revisions, so the four scheduled runs can make at most 400 API requests per day. This leaves headroom under the 500 requests/day shown for the current Free-tier project. The exact active quota remains controlled by Google AI Studio and can change; model RPM and input-token limits also apply. If the request budget runs out mid-lesson, that lesson is retried by the next scheduled run. Updated queues and completed lessons are committed automatically.

The worker processes only complete manifests and phases explicitly enabled for generation. It writes Markdown to `course/drafts/`, where generated output is labelled as a draft. A lesson must include exact required section headings, every supplied name in reference lessons, and at least one allowed source URL. Each lesson also receives an automated second-pass content review against the same frozen manifest. Specific issues trigger a bounded rewrite; both review and rewrite calls count against the 100-call run budget. DSA problem lessons each receive one manifest-supplied problem title and must include a standalone C# program with failing assertions. Before committing drafts, GitHub Actions builds and runs every DSA solution against its embedded sample and edge-case checks using .NET 10. Automated review reduces obvious omissions and contradictions but is not an independent factual guarantee.

No paid model fallback is configured. If the free-tier model returns an error or exhausts quota after retries, the run fails without enabling billing. The next scheduled run retries the pending lesson. Free-tier model requests may be used by Google to improve its products; check current provider terms before adding private or personal data to prompts.

Google's current documentation identifies `gemini-3.5-flash-lite` as a stable model and notes that rate limits vary by project and are visible in AI Studio: [model page](https://ai.google.dev/gemini-api/docs/models/gemini-3.5-flash-lite), [rate limits](https://ai.google.dev/gemini-api/docs/rate-limits), [pricing and free-tier data use](https://ai.google.dev/gemini-api/docs/pricing).
