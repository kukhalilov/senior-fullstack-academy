# Lesson-generation automation status

The GitHub Actions generation workflow was removed on 2026-11-17 at the repository owner's request. There is no GitHub scheduled, push-triggered, or manual generation job in `.github/workflows/`.

The local `npm run generate` command remains available for explicitly initiated local work. GitHub Actions is not responsible for generating, reviewing, or promoting lessons. Existing content under `course/drafts/` remains draft material until its claims and topic scope have been checked and recorded in `curriculum/factual-review-ledger.json`.

Historical implementation details are retained in Git history, not treated as current operating instructions.
